# Godot PCK Compressor

Десктоп-приложение для сжатия веб-билдов Godot: уменьшает `.pck` и `.wasm` файлы и автоматически патчит загрузчик движка, чтобы игра могла их распаковать в браузере.

> Ветка `web` — интерфейс на FastAPI + pywebview (нативное окно с веб-UI внутри).

## Возможности

- **Сжатие Gzip** (уровни 0–9) — декомпрессия в браузере через [pako](https://github.com/nodeca/pako).
- **Сжатие Brotli** (уровни 0–11) — декомпрессия через встроенный JS-декодер `brotli_inflate.min.js`.
- Отдельные уровни сжатия для `.wasm` и `.pck`.
- **Правка JS**: основной JS-файл билда просто меняется, чтобы сжатые `.wasm`/`.pck` распаковывались при загрузке игры.
- Декодер (`pako_inflate.min.js` / `brotli_inflate.min.js`) копируется в папку билда и подключается `<script>`-тегом в `.html` перед основным скриптом.
- **Бэкапы**: перед сжатием создаются копии `.pck.backup`, `.wasm.backup`, `.js.backup` (отключаемо).
- **Упаковка в ZIP** с исключением ненужных файлов (`.backup`, `.import`, `.png` и т.д.).
- Выбор платформы (Yandex, CrazyGames, Poko, PlayGamma) — пока заглушка.

## Установка и запуск

Требуется **Python 3.10+** (Windows).

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python run.py
```

Откроется нативное окно приложения (внутри — локальный сервер на `127.0.0.1:4000`, его можно открыть и в обычном браузере).

## Как пользоваться

1. **Выберите папку** с экспортированным веб-билдом Godot.
2. **Укажите HTML-файл** билда (например `index.html`).
3. Нажмите **«Проверить проект»** — приложение убедится, что рядом лежат `{имя}.js`, `{имя}.wasm`, `{имя}.pck`.
4. Выберите **алгоритм** (Gzip или Brotli) и уровни сжатия для `.wasm` и `.pck`.
5. Оставьте включёнными **бэкапы** и нажмите **«Сжать»**.
6. При желании — выберите **платформу** и/или соберите **ZIP** (исключения настраиваются).

После сжатия билд готов к загрузке на хостинг — распаковка происходит на стороне браузера при загрузке игры.

## Что именно делает сжатие

| Шаг | Gzip | Brotli |
|---|---|---|
| Правка `{имя}.js` | fetch оборачивается в `new Response(pako.inflate(buffer), ...)` | fetch оборачивается в `new Response(brotli.decompress(new Uint8Array(buffer)), ...)` |
| Подключение декодера | `pako_inflate.min.js` (~21 КБ) | `brotli_inflate.min.js` (~145 КБ) |
| Сжатие `.pck` / `.wasm` | `gzip` уровня 0–9 | `brotli` уровня 0–11 |
| Защита от повторного сжатия | по сигнатуре `\x1f\x8b` | потоковая проверка первых 4 МБ декомпрессором; gzip-сжатые файлы распознаются по сигнатуре |

## Известные ограничения

- `/platform` — заглушка (SDK-интеграции платформ ещё не реализованы).
